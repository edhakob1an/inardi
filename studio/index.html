About the studio

Every pixel matters

Each Pixel Matters is a small independent game studio from Armenia. We believe the small things decide whether a game feels cheap or special: how a die lands, how a checker clicks into place, how a board looks in the evening light.

So we sweat the details, and we build games we would happily play ourselves.
